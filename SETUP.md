# Setup and Warnings

Before you drop Scrubber into your game, there are a few things you should know. 

Scrubber is a hobby project and it's still being built out. Because of that, the way you get it and how up to date it is depends on where you grab it from.

## Where to get it

You have two choices, and it's completely up to you how you want to use it:

1. **The Roblox Creator Store:** You can grab the official model right here: [ScrubberService on Roblox](https://create.roblox.com/store/asset/74188375071458/ScrubberService)
2. **The GitHub Source (`src` folder):** You can copy the raw `.lua` files straight from this repository.

## The difference between the two

If a patch or a fix gets pushed out, **the Roblox Creator Store will update instantly.**

> [!IMPORTANT]
> The GitHub repository might be a little slower to get those same updates. Sometimes we forget to push the changes, or we're just testing something locally before updating the repo. If you want to make sure you always have the absolute latest version with all the newest fixes, grabbing it from the Roblox store is your best bet. If you prefer having the raw source code to read through and tweak yourself, use the `src` folder here.

## Things to keep in mind

*   **Where it goes:** When you bring Scrubber into your game, put the `ScrubberService` folder in `ServerScriptService` or anywhere safe and clean. 
*   **How to use it:** You can only use it by requiring it from a server script.

> [!CAUTION]
> If you're not a professional at editing Luau code, it's highly advised that you don't mess with the internals of the scripts. Just use the API as documented.

*   **It's still in development:** Things might break or change. If something looks off, it's probably a bug that will get fixed in a future update.
